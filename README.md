# QUARTO 3D

木製の盤と駒で遊ぶボードゲーム「Quarto」。Three.js による3D表示と、PeerJS (WebRTC) によるP2P対戦に対応したスマホ向けWebアプリです。

## 遊び方
- 「部屋をつくる」→ 表示された5文字コード（または共有リンク）を相手に伝える
- 相手は「部屋に入る」でコード入力、またはリンクを開く
- 「1台で2人対戦」でも遊べます
- ドラッグで視点回転、ピンチ/ホイールでズーム

## 開発
```
npm install
npm run dev       # LAN公開されるのでスマホから http://<PCのIP>:5173 で確認可
npm run build     # dist/ を静的ホスティング (GitHub Pages 等) に置くだけ
npm test          # ルール判定のテスト
```

## 通信について
- 接続の仲介（シグナリング）にだけ PeerJS 公開ブローカーを使い、対局データは端末間で直接送受信されます。
- 厳しいNAT（一部のモバイル回線など）では STUN だけでは繋がらないことがあります。その場合は TURN を用意して
  `VITE_TURN_URL` / `VITE_TURN_USER` / `VITE_TURN_PASS` を設定してビルドしてください。
- 本番は HTTPS で配信してください（共有ボタン・クリップボードに必要）。
